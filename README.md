## 🏨 Overview

This is the front-end application for the Cinnamon City Hotel booking system, providing users with an intuitive interface to search, view, and book hotel accommodations.

## ✨ Features

- User authentication and account management
- Hotel search and filtering
- Room availability checking
- Secure booking system
- Reservation management
- Responsive design for mobile and desktop

## 🛠 Tech Stack

- **React** - UI framework
- **JavaScript (ES6+)** - Programming language
- **CSS/Styled Components** - Styling
- **Axios/Fetch API** - HTTP client
- **React Router** - Routing
- **State Management** - Context API or Redux

## 📦 Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager
- Modern web browser

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/Erangamadhushan/Cinnamon-City-Hotel-booking-Front-End.git
cd Cinnamon-City-Hotel-booking-Front-End
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will open at `http://localhost:5173`

## 💻 Usage

- Navigate to the home page to search for hotels
- Filter results by date, price, and amenities
- Click on a hotel to view details
- Create an account or login to book
- Complete the booking process
- View and manage your reservations
